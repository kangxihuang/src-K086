# (附文档)Springboot3+Vue3+MySQL 校园外卖点餐系统

**技术栈**：Springboot3、Vue3、MySQL

### 系统简介

本系统是一款基于 Spring Boot 3 + Vue 3 + MySQL 构建的校园外卖点餐系统，采用前后端分离架构。系统包含学生用户端、商家端和管理员端三个角色，覆盖从商家入驻、菜品管理、用户点餐、购物车结算、订单流转到评价通知的完整外卖业务流程，适用于校园场景下的餐饮数字化管理。
 
### 核心功能
 
### 普通用户端

 
- 登录注册：支持学生用户通过用户名密码登录，或注册新账号（填写学号、真实姓名、手机号等信息）。 
- 个人中心：查看/编辑个人资料（头像、性别、手机号等），修改登录密码（需验证旧密码）。 
- 地址管理：新增/编辑/删除收货地址（宿舍楼+宿舍号），设置默认地址，自动按创建时间倒序排列。 
- 首页浏览：查看轮播图、店铺分类列表、热门商家推荐、热门菜品推荐、平台公告列表。 
- 商家与菜品：按分类或关键词搜索商家，进入店铺详情页查看菜品（按分类分组）、商家信息及用户评价。 
- 菜品搜索：全局搜索上架菜品（按名称模糊匹配，按销量降序），支持按商家筛选。 
- 购物车管理：添加菜品到购物车（同一菜品自动累加数量），修改数量或删除购物车项，按商家分组展示并计算小计。 
- 提交订单：从购物车选择菜品生成订单，选择收货地址、填写备注，创建订单后状态为“待接单”。 
- 订单管理：查看个人订单列表（按状态筛选），查看订单详情（含菜品明细、金额、商家信息）。 
- 订单操作：取消未接单的订单，申请退款（填写退款原因）、取消退款申请，确认收货（完成订单）。 
- 评价功能：对已完成的订单提交评价（评分1-5星、文字内容、关联菜品），查看自己的历史评价。 
- 消息通知：查看系统通知列表，标记单条或全部通知为已读，查看未读通知数量。
 
### 商家端

 
- 商家入驻：提交入驻申请（填写店铺名称、分类、地址、电话、营业时间、店铺描述等），等待管理员审核。 
- 店铺管理：查看/编辑店铺资料（logo、图片、描述、公告等），修改登录密码。 
- 营业开关：一键切换店铺营业/休息状态，休息时用户无法将菜品加入购物车。 
- 菜品分类管理：新增/编辑/删除菜品分类（设置分类名称和排序号），删除前需确保分类下无菜品。 
- 菜品管理：新增菜品（填写名称、价格、库存、图片、所属分类、描述等），编辑/删除菜品。 
- 菜品上下架：单独上架或下架菜品，下架后用户端不可见。 
- 订单处理：查看本店订单列表（按状态/关键词筛选），查看订单详情。 
- 订单流转：接单（待接单→备餐中）、标记出餐（备餐中→已出餐）、标记配送（已出餐→配送中）、完成（配送中→已完成）。 
- 退款处理：查看退款申请，同意或拒绝退款（同意后订单状态变为“已退款”）。 
- 评价管理：查看用户对本店的评价列表（按评分筛选），回复用户评价。 
- 消息通知：接收订单状态变更等通知，标记已读，查看未读数量。 
- 数据统计：查看店铺总览数据（订单数、营业额、菜品销量等）。
 
### 管理员端

 
- 个人中心：查看/编辑管理员个人信息，修改登录密码。 
- 用户管理：分页查询学生用户列表（按关键词/状态筛选），启用或禁用用户账号，删除用户。 
- 商家管理：分页查询商家列表（按关键词/审核状态/账号状态/店铺分类筛选），查看商家详情。 
- 商家审核：审核商家入驻申请（通过/拒绝并填写审核备注），启用或禁用商家账号。 
- 店铺分类管理：新增/编辑/删除店铺分类（设置分类名称、图标、排序号）。 
- 菜品管理：跨商家分页查询所有菜品（按关键词/状态/商家筛选），上下架菜品，删除菜品。 
- 订单管理：查看全平台订单列表（按状态/关键词筛选），查看订单详情（含用户、商家、菜品明细）。 
- 公告管理：新增/编辑/删除平台公告（标题、内容、类型：通知/活动，发布/下线状态）。 
- 轮播图管理：新增/编辑/删除首页轮播图（标题、图片、排序号、启用/下线状态）。 
- 数据统计：查看平台总览数据（用户数、商家数、订单数、营业额等）。
 
### 技术栈

  后端框架 Spring Boot 3.x   ORM MyBatis-Plus 3.5.x   权限认证 JWT（自定义拦截器 + UserContext）   前端框架 Vue 3.x   状态管理 Vuex / Pinia（视具体实现）   构建工具 Vite   数据库 MySQL 8.x   文件上传 MultipartFile + Hutool
